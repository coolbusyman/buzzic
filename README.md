# Buzzic

Buzzic = Node.js (Express) + React (Vite + Tailwind + Framer Motion).
- Manche guitare interactif
- Modes (incluant Mineur harmonique & Mineur mélodique)
- Chat "Demande à Platon" (analyse enrichie)
- Liens Songsterr automatiques (cache 7j)
- Mode sombre + splash screen + favicon Les Paul
